# 🛍️ Novin Shop | فروشگاه اینترنتی نوین‌شاپ

**A Modern E-Commerce Platform | یک پلتفرم فروشگاهی مدرن**

Novin Shop is a modern, responsive e-commerce website built with HTML, CSS, JavaScript and Node.js, designed to provide a complete online shopping experience.

نوین‌شاپ یک فروشگاه اینترنتی مدرن و واکنش‌گرا است که با هدف ایجاد تجربه‌ای کامل از خرید آنلاین توسعه داده شده است.

## ⚙️ Installation & Setup | نصب و راه‌اندازی

### Prerequisites | پیش‌نیازها

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/novin-shop-hosseinkhosravi.git
```

### 2. Enter the Project Folder

```bash
cd novin-shop-hosseinkhosravi/novin-shop-scroll-animations-social
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Server

```bash
npm start
```

### 5. Open the Website

Visit the following address in your browser:

```text
http://localhost:3000
```

### Troubleshooting | رفع مشکلات

- If port 3000 is already in use, stop the previous server before starting a new one.
- Make sure you are running commands inside the folder containing `package.json`.
- If dependencies are missing, run `npm install` again.
