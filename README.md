# 🛍️ Novin Shop | فروشگاه اینترنتی نوین‌شاپ

**A Modern E-Commerce Platform | یک پلتفرم فروشگاهی مدرن**

🌐 **Live Demo:** [Visit Novin Shop](https://novin-shop-hosseinkhosravi.onrender.com/)

Novin Shop is a modern, responsive e-commerce platform built with HTML, CSS, JavaScript and Node.js. It provides an online shopping experience with customer accounts, product management, shopping cart, order management and an administration dashboard.

نوین‌شاپ یک فروشگاه اینترنتی مدرن و واکنش‌گرا است که با هدف شبیه‌سازی و ارائه تجربه‌ای کامل از خرید آنلاین توسعه داده شده است.

## 🚀 Installation & Run Locally

Make sure Node.js and npm are installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/hossein999kh/novin-shop-hosseinkhosravi.git
   ```

2. Enter the project directory:

   ```bash
   cd novin-shop-hosseinkhosravi/novin-shop-scroll-animations-social
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open your browser:

   ```text
   http://localhost:3000
   ```
