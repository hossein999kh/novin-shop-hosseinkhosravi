# تغییرات آخرین نسخه نوین‌شاپ

## انبار و موجودی
- در بخش «انبار و موجودی»، فرم «افزودن سریع موجودی» را باز کن.
- محصول و تعداد ورودی را انتخاب کن و «افزودن به موجودی» را بزن.
- برای افزایش سریع از دکمه‌های +1، +5 و +10 کنار هر محصول استفاده کن.
- «اصلاح دقیق» برای جایگزین کردن مقدار موجودی با یک عدد مشخص است.
- جست‌وجو بر اساس نام یا SKU نیز اضافه شده است.

## گزارش‌ها
پنج نمودار ساخته می‌شود: فروش هفت روز اخیر، تعداد سفارش‌ها به تفکیک وضعیت، موجودی به تفکیک دسته‌بندی، اقلام پرتکرار در سفارش‌های معتبر و هشدار کمبود موجودی.

## نمای کلی
دو بخش جدید وجود دارد: دسترسی سریع به محصولات کم‌موجود و مرکز اقدام‌های مدیریتی با میانبرهای انبار، گزارش‌ها، سفارش‌ها و محصولات.

## اجرا
در پوشه اصلی پروژه:
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کن و از پنل مدیریت وارد بخش‌های «انبار و موجودی»، «گزارش‌ها» و «نمای کلی» شو.

## محدودیت
داده‌ها همچنان در localStorage همین مرورگر ذخیره می‌شوند. این تغییرات برای مدیریت محلی و آزمایش مناسب‌اند، اما جایگزین پایگاه داده سمت سرور و تراکنش امن موجودی در فروش واقعی نیستند. آزمون کامل مرورگری هنوز انجام نشده است.


## صفحه جزئیات محصول
- بازطراحی ساختار صفحه جزئیات با گالری، کارت خرید، اطلاعات فروشنده، امتیاز و مشخصات فنی
- افزودن تب‌های مشخصات، دیدگاه‌ها و پرسش‌ها و پاسخ‌ها
- افزودن ثبت پرسش برای کاربران واردشده و ذخیره محلی پرسش‌ها
- بهبود نمایش واکنش‌گرا و جدول مشخصات
